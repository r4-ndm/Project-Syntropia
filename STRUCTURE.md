## **Workflow**

### **For Humans (Phase 1):**
1. Read `requirements.md` for vision
2. Follow `phase1/plan.md` and `phase1/tasks.md`
3. Implement code in empty directories

### **For Agents (Future Phases):**
1. Read `README.md` for navigation
2. Check `big-picture/` for context
3. Audit / discuss / help brainstorm `*/raw/` folders
4. When asked, compile `raw/` → requirements
5. Implement following plan.md and tasks.md

## **Key Concepts**

### **Raw Folders**
- **Purpose**: Brainstorming nuggets
- **Content**: Ideas, diagrams, concepts, research
- **When ready**: Compiled into formal requirements
- **Example**: See `phase1/raw/eitri_*.md`

### **Phase Progression**
